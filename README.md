## ⚡ Overview

**Rivet Labs** is an AI-powered brand intelligence engine that transforms unformed, messy product ideas into battle-tested positioning strategies, strict visual design languages, adversarial critiques, and complete production-ready launch kits in seconds.

Instead of treating branding as decorative fluff or relying on lukewarm corporate clichés (*"empowering seamless journeys"*), Rivet Labs approaches brand identity as a **deterministic engineering discipline** with an uncompromising neo-brutalist technical terminal aesthetic.

## 🛠️ The 4-Stage Reasoning Pipeline

```
┌─────────────────┐     ┌──────────────────┐     ┌────────────────────┐     ┌─────────────────────┐
│  01 // DISCOVER │ ──> │ 02 // POSITION   │ ──> │  03 // CHALLENGE   │ ──> │  04 // DELIVER      │
│  Semantic Intent│     │ Dynamic Strategy │     │ Adversarial Critic │     │ Production Launch   │
│  & Raw Vector   │     │ & Customization  │     │ & Anti-Cliché Unit │     │ Kit & Assets        │
└─────────────────┘     └──────────────────┘     └────────────────────┘     └─────────────────────┘
```

### Stage 01 // DISCOVER: Semantic Intent Ingestion
* **Raw Prompt Analysis**: Ingests unstructured product descriptions, user pain points, and target demographics.
* **Rapid Seed Presets**: One-click injection presets for DevOps/Infrastructure, Local-First Health, and Algorithmic Media.
* **Deterministic Parsing**: Extracts the core functional problem and target personas without rigid template limits.

### Stage 02 // POSITION & SHAPE: Dynamic Parameter Mapping
* **Algorithmic Parameter Extraction**:
  * `PARAM_01: MARKET_CATEGORY` & Strategic Subtitle.
  * `PARAM_02: CORE_VALUE_PROPOSITION` & Target Audience Vector.
  * `PARAM_03: NAMING_PROTOCOLS`: Synthesizes 3 distinct naming options (*Kinetic Minimalist*, *Heavy Industrial*, *Pragmatic Builder*) backed by architectural rationales.
* **Live In-Place Customization**: Direct inline editing on every strategic parameter with global real-time synchronization across all downstream stages.

### Stage 03 // CHALLENGE: Adversarial Critic Network
* **Cliché Detection Engine**: Scans positioning copy against overused SaaS marketing buzzwords (*"seamless integration"*, *"AI-driven single pane of glass"*).
* **Brutalist Teardowns**: Delivers harsh, actionable critiques exposing weak value claims.
* **Adversarial Synthesis**: Reconstructs an improved, high-velocity value proposition alongside a provocative, anti-corporate rebel moniker (e.g., `HARDSTOP`, `COLDBLOOD`, `TIMBREKILL`).

### Stage 04 // DELIVER: Production Launch Kit
* **Color Mood & WCAG Contrast Engine**:
  * Real-time ITU-R BT.709 relative luminance calculations certifying **100% WCAG AA/AAA compliance**.
  * Dynamic HSL engine for Complementary, Triadic, and Monochromatic palette variations.
  * One-click CSS root variables copy.
* **Interactive Live Web Banner**:
  * Switchable layouts: **Hero Banner**, **Announcement Strip**, and **Callout Card**.
  * Responsive viewports (**Desktop** / **Mobile**) with copyable Tailwind JSX code.
* **Social Share Preview Generator (OpenGraph)**:
  * Generates 1200×630 landscape and 1080×1080 square social sharing cards.
  * 4 Brutalist CSS themes: *Monochromatic*, *High-Contrast Neon*, *Surgical Paper*, and *Brand Accent*.
  * Live feed unfurl simulation.
* **SEO Health Score & Search Intent Engine**:
  * Algorithmic audit calibrated for Google’s 600px desktop title tag limit (40–65 chars) and meta description snippet budget (120–160 chars).
  * Category search intent keyword saturation matrix (*Transactional*, *Commercial*, *Informational*).
  * Live Google desktop SERP simulation card.
  * One-click export for `<title>`, `<meta>`, and Schema.org `SoftwareApplication` JSON-LD structured data.
* **Executive Pitch Deck Generator**:
  * 4-slide widescreen (16:9) presentation blueprint covering Problem, Solution, Market, and Design System.
  * Autoplay mode with Dark/Light theme switching and Markdown export.
* **Brutalist Vector QR Code Generator**:
  * Generates high-contrast QR codes in *Paper High-Vis*, *Void Dark*, and *Matrix Green*.
  * Direct vector SVG and high-resolution PNG downloads.
* **Time-Travel Checkpoint System**:
  * In-memory workflow history permitting founders to save, compare, and roll back to previous brand iterations.

## 🚀 Getting Started

### Prerequisites
* **Node.js**: v18.0.0 or higher
* **npm**: v9.0.0 or higher

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/rivet-labs.git
   cd rivet-labs
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Run type-checking and linter**:
   ```bash
   npm run lint
   ```

## 📐 Design Philosophy: Neo-Brutalist Engineering

Rivet Labs follows strict visual and ergonomic principles:
* **Zero-Pill Discipline**: No pill-shaped tags or soft pastel bubbles. Form follows function through sharp 90-degree industrial borders and monospace telemetry.
* **Accessibility First**: Every generated color mood is verified via algorithmic relative luminance math to guarantee high-contrast legibility.
* **Real Production Code**: Every generated banner, SVG logo prompt, and metadata snippet can be dropped directly into production web apps.
